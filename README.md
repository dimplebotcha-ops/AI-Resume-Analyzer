# AI Resume & Job Description Analyzer

A beginner-friendly Streamlit web application that compares a resume with a job description and calculates a basic resume match percentage.

## Features

- Enter or paste a resume
- Enter or paste a job description
- Compare words between the resume and job description
- Calculate a basic resume match percentage
- Simple and easy-to-use interface

## Technologies Used

- Python
- Streamlit

## How to Run

1. Install Python.
2. Install Streamlit:

```bash
python -m pip install streamlit
